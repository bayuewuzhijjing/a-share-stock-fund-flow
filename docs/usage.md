# 使用说明

## 1. 启动页面

在项目根目录执行：

```powershell
python server.py
```

浏览器访问 <http://127.0.0.1:4176/>。如果端口被占用，可以先设置其他端口：

```powershell
$env:STOCK_FLOW_PORT=4177
python server.py
```

## 2. 第一次采样

点击页面右上角的“立即采样”。程序会从公开行情接口读取当前资金流数据，并写入本地数据库。采样完成后，页面会刷新题材雷达、今日综合强度候选和分时资金流排行榜。

如果接口暂时不可用，页面仍可以打开；请稍后重试，并检查 `/api/health` 是否返回正常结果。

## 3. 查看和筛选

- 在时间窗口中选择 1 分钟、5 分钟、15 分钟、30 分钟、60 分钟或更长周期。
- 使用“流速 / 净流入 / 加速度 / 强度”等指标切换排序逻辑。
- 在题材区域选择一个题材，查看该题材下的产业链分支和成员股。
- 在个股排行榜中点击股票，查看该股票的分时流速、历史累计和验证信息。

## 4. 维护公共配置

公共题材和自选股配置是普通 JSON 文件，适合通过 GitHub Pull Request 协作维护：

- `data/a_share_watchlist.json`：新增或调整默认自选股。
- `data/a_share_theme_pool.json`：新增题材、产业链分支和题材成员。
- `data/a_share_manual_pool.json`：本地临时添加的股票，通常不提交。

修改后运行：

```powershell
python tools/validate_library.py
```

校验通过后再提交 Pull Request。具体字段示例见 [题材与个股库协作方案](library-plan.md)。

## 5. 数据文件和隐私

运行产生的 `data/stock_fund_flow.db` 只保存在本机，用于历史回放和验证，不会被 Git 跟踪。不要把日志、缓存、`.env` 文件、账号信息或 API Key 提交到公共仓库。

## 6. 重要提示

公开行情接口可能有延迟、限流、字段变化和交易日差异。页面中的指标是对公开数据的计算结果，不能替代专业行情终端、公告核验或投资判断。
